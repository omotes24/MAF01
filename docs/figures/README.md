# Result Figures

This directory contains selected figures generated for the MAF report. The files
are committed so readers can inspect the main result trends directly from
GitHub, without rebuilding the PDF.

## Included

| File | Content |
| --- | --- |
| `main_auroc_fpr95_scatter.png` | Joint AUROC/FPR95 comparison on WILD_DATA. |
| `score_hist_maf_energy_rmd.png` | ID/OOD score histogram for MAF, Energy, and RMD. |
| `roc_curves.png` | ROC curves for major methods. |
| `pr_curves.png` | Precision-recall curves. |
| `tsne_dinov2_seed42.png` | DINOv2 feature t-SNE visualization. |
| `ood_species_breakdown_auroc_fpr95.png` | OOD species-level AUROC/FPR95 breakdown. |
| `backbone_auroc.png` | Backbone-level AUROC comparison. |
| `ablation_auroc.png` | Ablation comparison by AUROC. |
| `ablation_fpr95.png` | Ablation comparison by FPR95. |
| `covariance_eigenvalue_distribution.png` | Tied/class-wise covariance eigenvalue distribution. |
| `id_only_alpha_selection.png` | ID-only alpha selection analysis. |
| `bioclip_score_hist_maf_energy_rmd_seed42.png` | BioCLIP score histogram. |
| `mahalanobis_geometry.png` | Intuition for Mahalanobis geometry in feature space. |
| `wild_data_split.png` | WILD_DATA split summary. |

Figures containing raw representative dataset photographs, success examples, or
failure examples are not redistributed here unless image licensing is confirmed.
